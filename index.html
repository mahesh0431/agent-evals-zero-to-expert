How to use this course

Visual first

Every concept comes with a diagram of the mechanism: data flow, loops, side-by-side comparisons, real computed charts. Read the picture, then the prose.

Then precise

Definitions, formulas and runnable Python follow the intuition. Code uses real, current library APIs (Inspect, the Anthropic and OpenAI SDKs, Ragas, and more).

Then expert

"Expert corner" callouts cover the debates, failure modes and the way frontier labs and safety institutes actually run evals, with sources.

What you'll be able to do

  • Design an eval for any agent: tool-using assistants, coding agents, browser and desktop agents, voice agents, image and video agents, multi-agent systems.
  • Choose and validate graders, including LLM judges you can actually trust.
  • Report results with honest error bars, and know when a difference is real.
  • Read any benchmark paper or model system card critically: what it measures, how it is scored, how it can be gamed.
  • Pick the right tool (Inspect, promptfoo, Braintrust, LangSmith, Langfuse, DeepEval, Ragas, OpenAI Evals and others) and explain how they differ.
  • Explain how Anthropic, OpenAI, Google DeepMind and independent evaluators like METR and the UK AI Security Institute evaluate frontier models.
